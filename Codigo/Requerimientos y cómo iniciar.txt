REQUERIMIENTOS Y CÓMO INICIAR - SISTEMA VILLAFAÑE WIFI
=====================================================

El sistema está desarrollado con un stack moderno basado en PHP (Laravel 13) y MariaDB. A continuación, se detallan los requisitos previos y el paso a paso exacto para montar la base de datos e iniciar la aplicación hasta el punto donde quedó desarrollada (Módulos de Usuarios, Clientes, Planes, Servicios y Cuenta Corriente).

-----------------------------------------------------
1. REQUERIMIENTOS PREVIOS (ENTORNO DE DESARROLLO)
-----------------------------------------------------
Para poder ejecutar el sistema, la PC debe contar con el siguiente software instalado:

- PHP: Versión 8.3 o superior.
- Composer: Gestor de dependencias de PHP.
- Node.js y NPM: Para compilar los archivos y dependencias de frontend (JavaScript, CSS, Vite).
- Base de Datos: MariaDB 11.8 (o compatible, como MySQL). Se puede utilizar entornos integrados como XAMPP o Laragon para facilitar esto.

-----------------------------------------------------
2. PASO A PASO PARA PREPARAR EL SISTEMA (Primera vez o en otra PC)
-----------------------------------------------------
Al descargar o descomprimir el proyecto en una computadora nueva (por ejemplo, para evaluación), se deben seguir estos pasos:

PASO 1: Preparar la Base de Datos
1. Iniciar el servidor de base de datos local (por ejemplo, encendiendo los servicios de Apache y MySQL desde el panel de XAMPP o Laragon).
2. Entrar al gestor de base de datos (phpMyAdmin, DBeaver, HeidiSQL, etc.).
3. Crear una base de datos vacía que se llame exactamente: villafane_wifi

PASO 2: Abrir la terminal en la carpeta correcta del proyecto
1. Abrir la consola de comandos (PowerShell, CMD, o la terminal integrada de VSCode).
2. Ingresar a la carpeta "sistema" dentro de la estructura del código fuente del proyecto. El comando de navegación dependerá de dónde se haya extraído el sistema. Por ejemplo:
   cd "C:\Ruta\Donde\Descomprimiste\El\Proyecto\Codigo\VillafaneWifi-Gestion-y-atencion\sistema"
   (Asegúrese de reemplazar la ruta con la ubicación real en la que guardó los archivos).

PASO 3: Configurar las variables de entorno (.env)
1. En la consola (o desde el explorador de archivos), hacer una copia del archivo de ejemplo ".env.example" y renombrarlo simplemente como ".env":
   Ejemplo en consola: copy .env.example .env (en CMD) o Copy-Item .env.example .env (en PowerShell).
2. Abrir ese nuevo archivo ".env" en un editor de texto (como VSCode o el Bloc de Notas) y buscar la sección de base de datos.
3. Asegurarse de que las credenciales coincidan con el servidor local (el usuario por defecto en entornos como XAMPP suele ser "root" y la contraseña queda vacía):
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=villafane_wifi
   DB_USERNAME=root
   DB_PASSWORD=
4. En el mismo archivo .env, verificar y completar (si existen) las credenciales de la cuenta administradora inicial, buscando las variables que comiencen con ADMIN_INICIAL_*.

PASO 4: Instalar las dependencias de Backend
1. Ejecutar el siguiente comando para descargar las librerías de PHP:
   composer install

PASO 5: Generar la clave de la aplicación
1. Ejecutar el siguiente comando en la consola:
   php artisan key:generate

PASO 6: Instalar y compilar dependencias de Frontend (Diseño/JS)
1. Ejecutar para instalar las dependencias de Node:
   npm install
2. Ejecutar para compilar los recursos visuales y scripts (Vite):
   npm run build

PASO 7: Crear tablas y cargar datos iniciales (Migraciones y Seeders)
1. Para trasladar todo el esquema de la base de datos y cargar los datos de prueba pre-elaborados en la base "villafane_wifi", ejecutar:
   php artisan migrate --seed

PASO 8: Iniciar el Servidor de Desarrollo
1. Ejecutar el servidor local de Laravel:
   php artisan serve

PASO 9: Acceder al Sistema
1. Abrir el navegador web (Chrome, Edge, Firefox, etc.) e ingresar a la siguiente dirección:
   http://127.0.0.1:8000/iniciar-sesion
2. Iniciar sesión utilizando el correo y contraseña del administrador configurado.


-----------------------------------------------------
3. INICIAR EL SISTEMA RÁPIDAMENTE (Si ya fue configurado previamente en esa PC)
-----------------------------------------------------
Si ya se realizaron todos los pasos del punto 2 en el pasado y solo se desea volver a encender el sistema para probarlo:

1. Abrir PowerShell.
2. Navegar a la carpeta raíz del repositorio del código. Por ejemplo:
   cd "C:\Ruta\Donde\Descomprimiste\El\Proyecto\Codigo\VillafaneWifi-Gestion-y-atencion"
3. Ejecutar el script automatizado (provisto en el código) para levantar los servicios:
   powershell -ExecutionPolicy Bypass -File sistema\tools\windows\iniciar-aplicacion.ps1
4. Acceder en el navegador a: http://127.0.0.1:8000/iniciar-sesion
