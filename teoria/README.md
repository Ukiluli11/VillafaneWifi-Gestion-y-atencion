# Material teórico y entregables

Esta carpeta reúne únicamente el material vigente del proyecto:

- `documentacion/`: informe general, documentación técnica, manuales, guiones y
  documentos de trazabilidad.
- `diagramas/`: última fuente editable y vista previa de cada tipo de diagrama.
- `planificacion/`: cronograma vigente del proyecto.

Las versiones intermedias fueron retiradas para evitar que se utilice por error
un modelo desactualizado. Las entidades previstas para etapas futuras se
mantienen en los diagramas vigentes.
